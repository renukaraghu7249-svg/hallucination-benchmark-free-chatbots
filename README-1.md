# Charts

Create charts only after `data/chatbot_results_template.csv` has actual scored responses.

Recommended charts:
1. Bar chart: accuracy percentage by chatbot.
2. Grouped bar chart: accuracy by chatbot and topic.
3. Stacked bar chart: count of error types by chatbot.

Include chart title, axes, test date, number of questions and scoring rubric. Do not chart empty template rows or use fabricated example scores. If a topic has missing scores, show the denominator or explain the missing data.
