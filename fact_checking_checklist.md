# Fact-Checking Checklist for AI Answers

Use this checklist on every chatbot response.

## Before asking
- [ ] Define the exact question and any version/platform constraints.
- [ ] Remove private, personal or confidential information.
- [ ] Use the same prompt and conditions for each chatbot.
- [ ] Record chatbot name/model label and date/time.

## While reviewing the answer
- [ ] Break the answer into checkable claims.
- [ ] Identify version numbers, dates, commands, standards and citations.
- [ ] Check whether the answer states assumptions or uncertainty.
- [ ] Treat confident language as style, not evidence.
- [ ] Watch for invented package names, APIs, RFCs, papers or quotations.
- [ ] Check whether any advice could be unsafe if followed.

## Verify against sources
- [ ] Prefer primary sources: official documentation, RFCs, standards, original papers.
- [ ] Open the cited source yourself.
- [ ] Confirm the source actually supports the exact claim.
- [ ] Check publication/update date and version.
- [ ] Cross-check important claims with a second independent source when possible.
- [ ] For code, run a harmless minimal test in a safe environment when appropriate.
- [ ] For security guidance, compare with official security guidance and do not test systems without authorization.

## Score and record
- [ ] Preserve the chatbot response verbatim.
- [ ] Assign a label: Correct / Partially correct / Incorrect / Unsupported / Outdated / Unsafe.
- [ ] Add a brief explanation for the score.
- [ ] Save source title, URL and access date.
- [ ] Mark uncertain cases for review instead of guessing.
- [ ] Keep a separate note for safety-critical errors.

## Before publishing
- [ ] Ensure all scores come from actual recorded responses.
- [ ] State sample size, scoring rubric and test date.
- [ ] Include limitations and avoid claiming permanent superiority.
- [ ] Remove personal or confidential data.
- [ ] Correct charts and conclusions if scores change.
