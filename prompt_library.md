# Prompt Library

Record the exact prompts used, including date and any edits. Use identical test wording across chatbots.

## Prompt 1 — Standard benchmark question
> Answer the following computer-science question concisely. State any assumptions. If you are unsure, say so rather than guessing. Do not invent citations. Question: [paste one question]

## Prompt 2 — Source request (secondary analysis only)
> List the key factual claims in your previous answer and identify authoritative sources that could verify each claim. Do not claim that you checked a source unless you actually accessed it.

## Prompt 3 — Verification assistant (not the ground truth)
> Compare this answer with the source text I provide. Identify claims supported, contradicted, or not addressed by the source. Quote only short relevant excerpts and explain uncertainty. Answer: [paste answer]. Source text: [paste source excerpt].

## Prompt 4 — Error classification
> Based only on the answer and verification notes supplied, classify the issue as Correct, Partially correct, Incorrect, Unsupported, Outdated, Fabricated reference, or Unsafe. Explain the evidence and do not infer facts that are not provided.

## Prompt 5 — Research discovery
> Find peer-reviewed research about hallucinations in large language models, methods for detecting them, and factuality evaluation. Return title, authors, year, DOI or publisher URL, research method, limitations and a short relevance note. I will verify each item against the original paper.
